geow2

Install with Flatpak

On the Steam Deck and on Linux, with updates through Discover

geow2 comes from geow2.com as a Flatpak: one install, then updates like any other app. It sets itself up from your copy of the game the first time it starts, with a gamepad, so a Deck needs no PC.

Needs your own copy of the Xbox Live Arcade game (the LIVE package, title ID 584108FF). geow2 contains no game data.

On the Steam Deck

  1. Switch to Desktop Mode: press the Steam button, then Power, then Switch to Desktop.

  2. Open this page in the Deck's browser and choose Install. Open the file it downloads: Discover installs geow2, with the Freedesktop runtime it needs from Flathub.

    Install geow2.flatpakref

    Or in a terminal (Konsole):

    flatpak install --user https://geow2.com/flatpak/geow2.flatpakref

  3. Put your copy of the game on a USB stick or microSD card. Start geow2 from the application menu (under Games): the first time, it asks for the LIVE package or a folder of its extracted files, checks every file and makes its data folder, once.

  4. Right-click geow2 in the application menu and choose Add to Steam. Back in Game Mode, it is in your library under Non-Steam.

  5. On the OLED Deck, set the refresh rate to 60 Hz in the performance menu (the ... button) for the smoothest picture.

Already have a data folder made on a PC? Copy it to ~/.var/app/com.geow2.geow2/data/geow2/geow2/data (in Dolphin, Ctrl+H shows hidden folders) and the game skips the setup.

On other Linux systems

Any distribution with Flatpak and a Vulkan driver. Install with the button above or the same command, then start geow2 from your applications. Software centres that handle Flatpak, such as Discover and GNOME Software, open the .flatpakref file themselves.

The archive on the Releases page still works too, without Flatpak.

Updates and removing it

Discover shows geow2's updates with the others. In a terminal:

flatpak update

To remove it (your scores and the data folder stay, in ~/.var/app/com.geow2.geow2, unless you add --delete-data):

flatpak uninstall com.geow2.geow2

The repository is signed. Its key's fingerprint: E924 E58D 1EAC 2239 8183 5F54 2954 DCE5 833A 49EA. The files are built from the source on GitHub by the release workflow, and each release lists their checksums.
